# Current Run Rate (CRR) Formula and Scope

Current Run Rate (CRR) measures the average number of runs a batting side scores per completed over bowled during an innings.

The mathematical formula for Current Run Rate is:
`CRR = total_runs / overs_bowled`

When calculating CRR during an incomplete over with partial legal balls `b` (where `1 <= b <= 5`), the over fraction is expressed as `b / 6`, not decimal `.b`. For instance, after 14 overs and 3 legal balls, the divisor is `14 + (3 / 6) = 14.5 overs`. 

CRR is applicable across both the first and second innings of any cricket format. However, CRR is an empirical historical rate describing what has already occurred; it does not indicate what scoring pace is required to win.
